# Maintainers

Maintainers guide Titan's technical direction, review contributions, and help
keep releases and project documentation in a healthy state.

| Name | GitHub | Role |
| --- | --- | --- |
| Gwang-o Yun | [@yungwangoh](https://github.com/yungwangoh) | Project lead and maintainer |

## Responsibilities

Maintainers are responsible for:

- reviewing changes for correctness, compatibility, and maintainability;
- keeping the issue tracker and release process usable;
- documenting important architectural decisions and project limitations;
- responding to security and community concerns;
- helping contributors understand where a change belongs.

Maintainer status is based on sustained project involvement rather than a
fixed contribution count. New maintainers may be added after demonstrating
sound technical judgment, reliable reviews, and respectful collaboration over
time.
