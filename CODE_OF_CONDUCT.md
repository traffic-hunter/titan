# Code of Conduct

Titan is built in public, and everyone participating in the project should be
able to do so without hostility or harassment.

## Expected Behavior

- Be respectful when discussing code, design, and project direction.
- Critique ideas and implementations, not people.
- Give useful context when reporting a problem or disagreeing with a change.
- Make room for contributors with different levels of experience.
- Accept correction, and help repair a conversation when it goes wrong.

## Unacceptable Behavior

Harassment, threats, discriminatory language, personal attacks, deliberate
disruption, and publishing another person's private information are not
accepted in Titan project spaces.

## Enforcement

Maintainers may edit or remove comments, close discussions, reject
contributions, or temporarily or permanently restrict participation when this
policy is violated. Decisions should be proportionate, documented where
appropriate, and focused on protecting the community.

Report conduct concerns to the project lead listed in
[MAINTAINERS.md](MAINTAINERS.md). Do not open a public issue if a report
contains private or sensitive information. Reports will be reviewed as
privately and promptly as the available project tools allow.

This policy applies to repository discussions, issues, pull requests, reviews,
and other spaces where someone is representing Titan.
