# Contributing to Titan

Thanks for taking the time to improve Titan.

Start with the [contribution guide](docs/guide/CONTRIBUTING.md). It covers the
project's code style, branch and commit conventions, and the checks to run
before opening a pull request.

For a substantial change, open an issue first. This gives maintainers and
contributors a place to agree on the problem and the shape of the solution
before implementation begins.

## Community

All contributors are expected to follow the
[Code of Conduct](CODE_OF_CONDUCT.md). Security issues should be reported
privately as described in the [Security Policy](SECURITY.md).
